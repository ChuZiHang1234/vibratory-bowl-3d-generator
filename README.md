# 振动盘 3D 自动生成软件

本项目目标是开发一套可以导入零件模型，并自动生成匹配零件的振动盘 3D 图的软件。

软件按本地离线方向设计：零件模型解析、参数推荐、3D 预览、振动盘模型生成和 STL 导出都在本机完成，运行时不依赖网络服务。

## 核心流程

1. 用户导入零件模型。
2. 软件分析零件几何特征。
3. 系统自动推荐振动盘参数。
4. 用户可手动调整振动盘参数。
5. 软件生成振动盘 3D 预览模型。
6. 用户确认后导出 3D 文件或工程图。

## 功能模块

### 1. 模型导入

- 支持导入常见 3D 零件格式。
- 第一阶段建议支持：
  - STL
  - STEP
  - OBJ
- 后续可扩展支持：
  - SolidWorks 零件
  - SolidWorks 装配体

### 2. 零件几何分析

导入零件后，软件自动分析：

- 外形长、宽、高
- 包围盒尺寸
- 体积
- 重心
- 主要接触面
- 可能的稳定姿态
- 推荐输送方向
- 推荐轨道宽度
- 推荐盘体尺寸

### 3. 振动盘参数生成

系统根据零件模型自动生成初始振动盘参数，包括：

- 盘体直径
- 盘体高度
- 螺旋轨道宽度
- 螺旋轨道高度
- 轨道圈数
- 轨道倾角
- 出料口宽度
- 出料口高度
- 挡边高度
- 底座尺寸

### 4. 用户自定义参数

用户可以在自动推荐参数基础上手动调整振动盘参数。

建议第一版支持以下可调参数：

| 参数 | 说明 |
| --- | --- |
| 盘体长度 | 非圆形或定制盘体的整体长度 |
| 盘体宽度 | 非圆形或定制盘体的整体宽度 |
| 盘体高度 | 振动盘整体高度 |
| 盘体直径 | 圆形振动盘外径 |
| 侧壁轮廓 | 圆形盘可选择柱形直壁或锥形扩口 |
| 底部直径比例 | 锥形盘底部直径相对顶部直径的比例 |
| 螺圈数量 | 螺旋轨道绕盘圈数 |
| 轨道宽度 | 零件通过轨道的宽度 |
| 轨道高度 | 螺旋轨道相对盘底的高度 |
| 轨道倾角 | 零件上升输送的倾斜角度 |
| 挡边高度 | 防止零件掉落的边缘高度 |
| 出料口宽度 | 出料位置的开口宽度 |
| 出料方向 | 顺时针或逆时针 |
| 出料姿态 | 可选择不限制、正面朝上、背面朝上、侧面朝上或立式出料 |
| 底座长度 | 振动盘底座长度 |
| 底座宽度 | 振动盘底座宽度 |
| 底座高度 | 振动盘底座高度 |

参数调整后，3D 预览应实时或手动刷新。

### 5. 3D 自动建模

根据自动推荐参数和用户自定义参数，生成参数化振动盘模型：

- 盘体
- 底座
- 螺旋轨道
- 挡边
- 出料口
- 简化筛选结构

第一版可以先生成简化工程模型，后续再增加复杂筛选机构。

### 6. 预览与导出

- 软件内置 3D 预览窗口。
- 支持旋转、缩放、平移查看模型。
- 支持导出：
  - STL
  - OBJ
  - STEP
  - 后续支持 SolidWorks 文件

## 本地离线架构

第一版采用：

- React + Vite：本地界面和参数面板。
- Three.js：本地 3D 预览、STL/OBJ 读取、参数化模型生成。
- Electron：后续打包成 Windows 独立桌面软件。

运行时原则：

- 不上传零件模型。
- 不调用云端建模接口。
- 不依赖在线 3D 服务。
- 所有推荐参数和 3D 生成逻辑都在本地代码执行。

## 当前原型运行方式

开发预览：

```bash
npm.cmd run dev
```

桌面窗口预览：

```bash
npm.cmd run desktop:dev
```

构建本地静态版本：

```bash
npm.cmd run build
```

打包 Windows 安装程序：

```bash
npm.cmd run package:win
```

安装程序会在安装过程中询问是否创建桌面快捷方式。

如需打包免安装便携版：

```bash
npm.cmd run package:portable
```

> 依赖安装和打包阶段需要下载本地开发依赖；打包后的软件运行时不需要联网。

## 第一版开发目标

第一版建议先完成：

1. 导入 STL、OBJ 或 STEP 零件模型。
2. 自动读取零件长宽高。
3. 自动生成推荐振动盘参数。
4. 用户可以修改盘体尺寸、轨道宽度、轨道圈数、出料方向等参数。
5. 生成简化振动盘 3D 预览。
6. 支持导出 STL、OBJ、STEP。

## 已完成的第一版原型能力

- 本地 STL / OBJ / STEP 零件导入。
- 本地计算零件长、宽、高、体积、稳定接触面和推荐出料方向。
- 自动推荐振动盘初始参数。
- 用户自定义盘体直径、长宽高、侧壁轮廓、底部直径比例、壁厚、底厚、螺圈数量、轨道宽度、爬升角度、挡边高度、出料口尺寸、出料方向、出料姿态和底座尺寸。
- Three.js 本地 3D 预览。
- 出料口可根据正面朝上、背面朝上、侧面朝上或立式出料生成对应导向结构。
- 本地导出参数化振动盘 STL、OBJ、STEP。
